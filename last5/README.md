# Last5 — brand and templates

Last5 is the working name for the exit-ticket platform for US K-12 schools: in the last
5 minutes of a lesson, students answer 3–5 quick questions and the teacher sees who
understood, who was engaged, and what to reteach tomorrow. The product concept
(English and Georgian) lives in the shared Claude doc "Last5 — Product Concept for US Schools".

## brand/

| File | Use |
|---|---|
| `last5-logo.svg`, `last5-logo.png` | Horizontal logo for light backgrounds |
| `last5-logo-white.svg`, `last5-logo-white.png` | Horizontal logo for dark backgrounds |
| `last5-mark.svg`, `last5-mark-white.svg` | Symbol only (favicon, avatars) |
| `last5-app-icon.svg`, `last5-app-icon-512.png` | App icon (navy rounded square) |
| `last5-brand-board.png` | Logo, app icon, colors and slogan on one page |

The symbol is a clock whose hands form a check mark; the coral slice is the last five
minutes before the hour. Colors: Navy `#142045`, Coral `#F25C3B`, Ink `#1F2937`.
The wordmark is Inter Display Bold (SIL Open Font License), converted to outlines, so
the SVGs need no font installed.

Slogan: "Know who got it before the bell."

## templates/

`Last5_Import_Template.xlsx` — bulk import of teachers, classes and students. Sheets:
Instructions, Teachers, Classes, Students. Row 1 holds the column names, row 2 is an
example, data starts at row 3. Role and Grade have drop-down lists; School email and
Student code are validated.
